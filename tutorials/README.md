## Conformance notes

- **Standalone carrier (ST1–ST8):** no clone, repository install or repository import on the default path.
  Section 2 is `src/timesfm_forecasting/` verbatim — seven cells tagged `metadata.dimer.embedded_module`
  in dependency order (`config`, `errors`, `data`, `model`, `forecasting`, `evaluation`, `provenance`); the
  only rewrites make the default weights directory working-directory-relative and remove the
  package-relative imports. Section 3 carries the manifest inline and asserts it against the module before
  anything is fetched. Section 1 carries the pins and the full hash lock.
- **Isolated runtime (RUN1, RUN10, ENV6):** nothing is pip-installed into the kernel; one kernel cell
  downloads a size- and SHA-256-checked `uv` wheel, builds a managed CPython 3.12.12 environment keyed on
  the lock digest (reused by a re-run or a second `Run all`), installs the 52 locked wheels with
  `--require-hashes --only-binary :all:`, and routes every later cell to one persistent worker with
  `MPLBACKEND=Agg` and `PYTHONPATH`/`PYTHONHOME`/`PYTHONSTARTUP` dropped. Re-running the cell keeps the live
  worker and its variables.
- **Guided layer (GDL1–GDL15):** audience and prerequisites, How to use this notebook, roadmap, Input → Model
  → Output, observable objectives, a prediction before each principal result, What to notice after each
  stage, collapsible Check your reasoning answers (qualitative; no recorded run yet), one
  Predict → Change one thing → Run → Observe → Explain activity, Infrastructure labels with collapsed
  cells, troubleshooting, a conclusion scaffold and a glossary.
- **Evaluation (SPL4, EVAL13, UNC5, §21.3):** chronological tail holdout with a printed leakage check; naive,
  seasonal-naive and SES baselines scored first; the point forecast is the median; quantiles are described
  as model quantiles with measured coverage; no quality assert — the report records verdicts.
- **Executor interface (EXE1–EXE6):** every reader-changeable value is a `# @param` form field; the BYOD
  branch reads `BYOD_PATH` and imports `google.colab` only when the path is empty; outputs go to `outputs/`
  relative to the working directory; `DIMER_NOTEBOOK_CI_PREINSTALLED=1` is the only environment variable read
  (an optimisation, never a data selector).
